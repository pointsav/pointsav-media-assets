# Activos de Marca PointSav

Activos de marca, primitivos visuales y archivos de identidad institucional para PointSav Digital Systems.

Todos los archivos de este repositorio siguen una taxonomía de prefijos estricta:

- `ASSET-*` — Archivos vectoriales y primitivos de interfaz de usuario (por ejemplo, `ASSET-FAVICON-SQUARE.svg`)
- `TOKEN-*` — Variables del sistema de diseño
